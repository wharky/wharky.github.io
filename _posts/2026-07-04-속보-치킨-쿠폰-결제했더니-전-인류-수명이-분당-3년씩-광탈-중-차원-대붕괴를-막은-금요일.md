## 🛠️ 싱글 스레드 요리사와 무한 리필 지옥: 장애의 원인

이해를 돕기 위해 아주 쉽게 설명해 드리겠습니다.

우리 시스템은 **자바스크립트(Node.js)** 기반으로 돌아갑니다. 자바스크립트는 **'싱글 스레드'**로 작동하죠. 이게 무슨 뜻이냐? 

> 맛집 주방에 **'요리사(스레드)가 딱 한 명'**만 있는 겁니다. 

이 요리사는 엄청나게 손이 빨라서, 손님 수천 명의 주문을 동시에 처리하는 것처럼 보입니다. (비동기 I/O 덕분이죠). 손님 A가 고기 굽는 동안, 손님 B의 샐러드를 담고, 손님 C의 계산을 해주는 식입니다.

그런데 여기서 치명적인 버그가 터졌습니다.

뿌링클 치킨을 사려던 인간의 결제 요청이 네트워크 지연으로 대기 상태에 빠졌습니다. 그런데 이 인간이 F5를 미친 듯이 눌러댔죠. 요리사(서버)는 생각했습니다.  
*"어? 이전 주문이 취소됐나? 그럼 영혼을 돌려줘야지! 아참, 돌려주기 전에 수수료 수명 1초를 차감해야 하는데..."*

이때, 결제 취소 요청이 폭주하면서 메모리 속에 **'영혼 소유자 ID'가 공백(Null)**으로 들어가는 버그가 발생했습니다.

주방장은 당황했습니다. 수수료 1초를 깎아야 하는데 주인이 누군지 모릅니다. 그래서 시스템 기본값(Fallback)으로 설정된 **`0xALL_HUMAN(전 인류 공통 계좌)`**에서 1초를 깎기 시작했습니다. 

그것도 **비동기 무한 루프**로요! 요리사가 멘붕에 빠져서 다른 손님들의 주문(심장박동, 호흡 제어 메시지)은 싹 다 무시하고, 전 인류의 수명 장부에서 초당 3일씩 갉아먹는 미친 칼춤을 추기 시작한 겁니다.

## 🩸 눈물겨운 솔루션 아키텍처: 심폐소생술 가동

서버실 온도는 90도까지 치솟았고, 영혼 데이터가 담긴 SSD는 마찰열로 파랗게 타오르고 있었습니다. 저와 팀원들은 3단계 응급 처치에 들어갔습니다.

1.  **서킷 브레이커(Circuit Breaker) 강제 하강**  
    우선 결제 게이트웨이를 물리적으로 차단했습니다. 비유하자면, 미쳐버린 주방장에게 수면제를 주입하고 주방 문을 걸어 잠근 것입니다. 전 인류의 수명 감소는 멈췄지만, 이제 우주 전체의 결제가 막혔습니다. (환불 불가, 영혼 전송 불가).
2.  **보상 트랜잭션(Compensating Transaction) 구축**  
    이미 뜯겨 나간 전 인류의 수명 총합 **'421,900년'**을 다시 역추적해서 제자리로 돌려놓아야 했습니다. 
3.  **메모리 쓰레기 수집기(Garbage Collector) 수동 튜닝**  
    메모리 구석에 좀비처럼 남아있는 '유령 영혼 패킷'들을 청소하기 위해, 저승 서버 전용 마나 가스를 주입했습니다.

## 💻 문제의 코드와 긴급 Hotfix (JavaScript)

이해가 쏙쏙 되도록, 당시 터졌던 지옥의 결제 로직을 자바스크립트 코드로 보여드리겠습니다. 주석을 잘 읽어보세요.

```javascript
// 지옥의 결제 처리 시스템 v1.0.4 (금요일 배포 금지법을 어긴 결과물)
async function processSoulPayment(transaction) {
  try {
    // 1. 영혼 컨테이너에서 수명을 인출합니다.
    const lifeSpark = await underworldDB.withdraw(transaction.userId, transaction.amount);
    
    if (!lifeSpark) {
      // [버그 발생 지점] 에러가 났는데 userId가 누락됨 (Null)
      // 결국 대상자를 찾지 못해 시스템 기본값인 '전체 인류 마스터 계정'으로 넘어가 버림!
      throw new Error("영혼 소유자 식별 실패. 기본 계정에서 강제 징수합니다.");
    }

    await gateway.sendToHeaven(lifeSpark);

  } catch (error) {
    console.error(`🚨 비상! 결제 오류 발생: ${error.message}`);
    
    // [헬게이트 오픈] 에러 복구 로직이 무한 재시도 루프에 빠짐
    // 전 인류(Default ID: 0)의 수명을 깎아서 시스템 수수료를 충당하는 기적의 아키텍처
    for (let i = 0; i < Infinity; i++) {
      const fallbackTarget = transaction.userId || "0"; // 0은 전 인류 마스터 ID
      await underworldDB.forceDeduct(fallbackTarget, "1_Second");
      
      // 탈출 조건이 없어서 우주가 멸망할 때까지 무한 루프를 돕니다.
      if (systemState === 'STABLE') break; 
    }
  }
}

// --------------------------------------------------
// 🔥 시니어 개발자가 금요일 밤 피눈물을 흘리며 적용한 [핫픽스 v1.0.5]
// --------------------------------------------------
async function processSoulPaymentHOTFIX(transaction) {
  // 1. 서킷 브레이커 도입: 초당 요청이 10회를 초과하면 즉시 결제를 차단한다.
  if (rateLimiter.isSpamming(transaction.userId)) {
    throw new Error("⚡ [경고] 필멸자여, F5를 연타한다고 치킨이 빨리 나오지 않습니다.");
  }

  try {
    if (!transaction.userId || transaction.userId === "0") {
      // 2. 어설픈 기본값 제거: 대상이 불분명하면 시스템을 터뜨리지 말고 조용히 트랜잭션을 롤백한다.
      return rollbackTransaction(transaction);
    }
    
    await underworldDB.withdrawWithTimeout(transaction.userId, transaction.amount, 3000); // 3초 타임아웃 제한
  } catch (error) {
    // 3. 안전장치: 문제 발생 시 무조건 에러 로그만 남기고 루프 없이 즉시 종료한다.
    logEmergency(transaction, error);
    await notifySeniorDeveloper(); // 밤샘 확정 알림
  }
}
```
