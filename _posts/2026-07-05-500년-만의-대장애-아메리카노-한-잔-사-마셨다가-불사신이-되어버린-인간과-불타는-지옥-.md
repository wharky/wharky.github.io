## 😱 도대체 왜 이런 일이? (feat. 지옥의 결제 루프)

자, 쉽게 설명해 드릴게요. 
우리가 카드를 긁을 때 아주 잠깐 딩- 동- 하고 로딩이 돌죠? 이걸 IT 용어로 **비동기 통신(Asynchronous)**이라고 합니다. 

배달 앱으로 치킨을 시켰는데 결제 완료 화면이 안 뜨는 상황을 상상해 보세요. 성질 급한 우리는 어떻게 하죠? 뒤로 가기를 눌렀다가 다시 결제 버튼을 광클합니다. 

이계의 결제 서버에서도 똑같은 일이 일어났습니다.

1.  대학생 김덕배가 음료수를 사고 **'수명 10분'**을 결제함.
2.  차원 간 게이트웨이가 졸았는지 결제 완료 신호를 안 보냄.
3.  지옥의 결제 봇(Scheduler)이 "어? 결제 실패인가?" 하고 **초당 2억 번의 재시도(Retry)**를 보냄.
4.  김덕배의 수명이 순식간에 `0분`을 돌파해 `-10분`이 됨.

### 💡 여기서 터진 대참사: 언더플로우(Underflow)
컴퓨터는 바보라서 마이너스(-) 개념을 이해 못 할 때가 있습니다. 
예를 들어 숫자를 저장하는 상자의 한계가 `0`까지인데, 여기서 1을 더 빼버리면? 

> **"에라 모르겠다! 가장 큰 숫자로 돌아가자!"**

하고 뒤로 휙 돌아버립니다. 주행거리가 99,999km인 중고차의 계기판이 0km로 리셋되는 것과 반대 현상이죠. 
결국 김덕배의 수명은 음수(-1)가 되는 순간, 시스템이 허용하는 우주 최대의 숫자(64비트 정수형 최대치)인 **18경 년**으로 치솟아 버렸습니다.

현재 김덕배는 동네 편의점에서 몸에서 신성한 황금빛 아우라를 뿜어내며 공중 부양 중이고, 지옥 서버실은 그의 '무한 동력 영혼 에너지'를 감당하지 못해 퓨즈가 다 터져나가고 있습니다.

## 💻 가상 코드로 보는 지옥의 결제 시스템 hot-fix

당시 수천 명의 엘프/오크 개발자들이 모니터를 보며 피눈물을 흘리며 짠 JavaScript(Node.js) 긴급 패치 코드입니다. 

```javascript
// 지옥의 영혼 결제 처리 함수 (긴급 핫픽스 버전)
async function processSoulPayment(userId, costLifespan) {
    const user = await Database.getUser(userId);

    // [버그 방어] 사용자의 수명이 마이너스가 되려고 하면 즉시 차단한다!
    if (user.remainingLifespan - costLifespan < 0) {
        throw new Error("❌ [시스템 경고] 영혼 잔액 부족! 이 손님 데려가면 우주 물리 엔진 터집니다.");
    }

    try {
        // 비동기 처리 중 네트워크 끊김을 대비한 타임아웃 3초 설정
        const paymentResult = await Promise.race([
            Gateway.charge(userId, costLifespan),
            new Promise((_, reject) => setTimeout(() => reject(new Error("Timeout")), 3000))
        ]);

        return paymentResult;
    } catch (error) {
        console.error(`🚨 결제 도중 에러 발생: ${error.message}`);
        
        // [핵심 패치] 에러 났다고 무한 재시도하지 말고, 안전하게 거래를 취소한다.
        return rollbackTransaction(userId, costLifespan);
    }
}

// [사후 처리] 이미 신이 되어버린 김덕배 전용 강등 함수
function downgradeDeityToHuman(userId) {
    const user = Database.getUser(userId);
    if (user.remainingLifespan > 100000000000000) {
        console.log("🛠️ 불사신 감지! 강제 빨대 꽂기 프로토콜 가동.");
        
        const excessLifespan = user.remainingLifespan - 80; // 딱 80년만 남기고 압수
        ServerRoom.absorbEnergy(excessLifespan); // 남는 수명은 서버실 전력으로 소모
        user.remainingLifespan = 80; // 평범한 인간으로 롤백
        
        console.log("😇 김덕배는 다시 평범한 대학생으로 돌아갔습니다. (시험 공부하러 감)");
    }
}
```
